Åbn det du skal bruge

Første opsætning
  1. Opret to repos i organisationen: ai-board (boardets kode — må gerne være offentligt, der er ingen data i det) og ai-board-data (privat).
  2. Kopiér filerne til ai-board — alt undtagen data.json. Læg data.json i roden af ai-board-data.
  3. Slå Pages til for ai-board: Settings → Pages → Deploy from a branch → main / root. Kan du vælge synlighed, så vælg Public — ellers skal brugerne have en GitHub-konto.
  4. Ret config.js i ai-board: sæt dataRepo til org/ai-board-data og contact til dit navn.
  5. Opret to tokens via Opret token ↗. Begge med: Resource owner = organisationen · Expiration = så lang som tilladt · Repository access = Only select repositories → ai-board-data.
    • AI Board – visning: Permissions → Contents → Read-only
    • AI Board – redigering: Permissions → Contents → Read and write
    Kræver organisationen godkendelse, ligger de som "pending" til en admin har godkendt dem.
  6. Indsæt dem under Adgang og tryk Gem og test. Begge skal vise ✓.
  7. Send links: redigeringslinket personligt til redaktørerne, visningslinket til resten. Kopiér besked giver en færdig tekst.
Et link er lækket, eller en redaktør skal fjernes
  1. Opret et nyt token med samme opsætning (Opret token ↗).
  2. Indsæt det under Adgang → Gem og test.
  3. Send det nye link til dem, der stadig skal have adgang.
  4. Slet det gamle token under Dine tokens ↗ — så holder det gamle link op med at virke med det samme.
Et link udløber snart
  • Udløbsdatoen står ved linket øverst (når GitHub oplyser den) og under Dine tokens ↗.
  • Under tokenet på GitHub kan du vælge Regenerate token: samme rettigheder, ny udløbsdato — men en ny værdi, så linket skal sendes ud igen.
  • Sæt en påmindelse i kalenderen en uge før.
Nogen har slettet eller ødelagt noget
  1. Åbn Ændringshistorik ↗ og find den sidste gode version — hver linje viser navn og hvilke initiativer der blev rettet.
  2. Klik på ændringen → ⋯ → View file → Raw, og kopiér hele teksten.
  3. Åbn data.json ↗ → blyanten (Edit) → erstat alt med det kopierede → Commit changes.
  4. Redaktører med boardet åbent får den gendannede version inden for et halvt minut.
Sådan virker det
  • Boardet (ai-board) er kun kode. Data ligger i data.json i det private ai-board-data.
  • Linkene bærer et token efter #. Den del sendes aldrig til nogen server, og boardet fjerner den fra adresselinjen og husker den i browseren.
  • Hver gemning bliver en ændring i ai-board-data med redaktørens navn. Retter to samtidig, flettes ændringerne sammen.
  • Redaktører ser hinandens ændringer inden for ca. 30 sekunder.
  • Et token kan kun læse/skrive ai-board-data — ikke boardets kode eller andre repos.
